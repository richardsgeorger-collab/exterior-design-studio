# Exterior Design Studio

AI-powered exterior design and quoting tool built for roofing and exterior contractors.

Upload a house photo, select elements to change (roof, siding, gutters, fascia, front door, 
and more), pick colors and materials — and get a photorealistic preview in ~45 seconds. 
Only what you ask changes. Nothing else.

Built for Utah Roofing and Exteriors. Powered by GPT-image-1 and Streamlit.

## Features
- Photorealistic AI image editing via GPT-image-1
- 9 exterior elements: roof, siding, gutters, fascia, soffit, front door, shutters, garage door, gables
- Color and texture picker with live previews
- Design themes (Modern, Traditional, California Cool, Mountain Lodge)
- Landscaping presets
- Before/after slider
- EagleView PDF parsing — auto-fills measurements from uploaded reports
- Full quote builder with materials, labor, waste factor, and profit margin
- Professional PDF quote export
- Save and compare designs
